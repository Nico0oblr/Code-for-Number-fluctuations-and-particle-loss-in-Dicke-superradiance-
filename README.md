# Reconstruction data for Dicke superradiance

Scientific data accompanying *Number fluctuations and particle loss in Dicke
superradiance* by Christian Niehof, Nico S. Baßler, and Claudiu Genes.

| Figure | Dataset |
| --- | --- |
| Fig. 5: particle-number reconstruction | [fig5_results.jld2](reconstruction/fig5/data/fig5_results.jld2) |
| Fig. S4: smoothing and moment reconstruction | [figS4_results.jld2](reconstruction/figS4/data/figS4_results.jld2) |

Each JLD2 file contains the saved study settings, binned observations,
intensity kernels, and reconstruction fits.
