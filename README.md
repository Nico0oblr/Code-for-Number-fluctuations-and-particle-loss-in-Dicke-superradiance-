# Code and data for Dicke superradiance

Code and data accompanying *Number fluctuations and particle loss
in Dicke superradiance* by Christian Niehof, Nico S. Baßler, and Claudiu Genes.

| Figures | Code and saved data |
| --- | --- |
| Fig. 4(b-e), Fig. 7(a-d) | [Intensity profiles and particle loss (Python)](superradiance/README.md) |
| Fig. 5(b-e), Fig. S4 | [Particle-number reconstruction (Julia)](reconstruction/README.md) |

Both folders include instructions for plotting the saved data and running
the simulations. You can reproduce the numerical plots without rerunning
the simulations or downloading the full population histories.
