# Code and data for Dicke superradiance

Scientific code and data accompanying *Number fluctuations and particle loss
in Dicke superradiance* by Christian Niehof, Nico S. Baßler, and Claudiu Genes.

| Figures | Code and saved data |
| --- | --- |
| Fig. 4(b-e), Fig. 7(a-d) | [Intensity profiles and particle loss (Python)](superradiance/README.md) |
| Fig. 5(b-e), Fig. S4 | [Particle-number reconstruction (Julia)](reconstruction/README.md) |

Each package contains numerical model code, plotting scripts, saved data,
and instructions for plotting and regeneration. The Fig. 7(b) data are
small summaries of the full Dicke-triangle population histories; plotting
does not require the original gigabyte-sized files.

Limitations of historical population caches are documented in the
[data notes](superradiance/data/README.md#historical-population-cache-labels).
The supplied Fig. 7(b) summaries use regenerated, normalized populations.
